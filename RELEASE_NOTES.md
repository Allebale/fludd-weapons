Mod API: 1.8

For the stable game with mod API 1.8 (launcher Stable 1.2.0 and newer). On an older game (mod API 1.7), use v1.0.3.

**New in 1.4.0**
- **Ice goop:** black goop can turn to ice when another mod asks for it (the Christmas Additions mod does): white-blue ice instead of black, just as slippery and fast, and enemies it touches freeze solid where they stand before they are defeated.
- Built with the final mod SDK 1.8.0: no more pre-release, and no rebuild warning.

Also in this release since v1.0.3: the 1.3 weapons and fixes. See the [changelog](https://github.com/Allebale/fludd-weapons/blob/main/CHANGELOG.md) for everything.

**Install:** unzip into your `mods` folder and turn it on in the Mods menu (F1).
